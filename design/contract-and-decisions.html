How this works — statutes and code

The interception-ledger (wiki) is the statute book: append-only DEC events. The docs are the codified current law: normative rules live inline as CONTRACT blocks in the doc they impact (📖 the spec · 🏛 the product book · 🛠️ the plan · 🔬 the search surfaces), and a contract block wins over any prose, anywhere. This page is only the queue of open cards and the block index below. A card, once ruled, dissolves into its block (stamped with the DEC number) and a ledger row — cards are a queue, not storage.
