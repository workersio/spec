The rules of the set

One fact, one home. Cross-doc references are citations, never restatement — an amendment touches one page plus pointers, or it's in the wrong doc. · Contract blocks are normative (styled callouts with a CONTRACT chip, indexed in 📜); they win over any prose. The interception-ledger holds the append-only DEC events; the docs hold the codified current law. · Ownership by change type: a decision → 📜 queue then its block · a build learning → 📖 · a phase landing → 🛠️ · a new argument → ⚗️ · a UX/packaging consequence → 🏛. · Change rules: search-space-class doc edits auto-apply (journaled); anything touching a contract block needs a DEC row. · Staleness contract: ⚗️ 🏛 📖 stable · 🛠️ weekly · this index structural-only. · Brainstorms are queues: disposable whiteboard artifacts fold into the set within days, then tombstone — if you can't point to the block or section that carries an idea, it isn't decided. · Artifacts are canonical; repo files are derived.
